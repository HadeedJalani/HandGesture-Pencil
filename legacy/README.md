# Legacy Prototypes

Early single-file scripts written while prototyping hand tracking and
gesture-based drawing, kept here for reference. They are **not** used by the
application — the real, modular implementation lives in the project root
(`main.py` and friends).

| File | What it explored |
|---|---|
| `webcam_canvas.py` | Basic idea: overlay a static drawing on a webcam feed. |
| `handtrack_demo.py` | First MediaPipe Hands integration + finger-state detection. |
| `demo_drawing.py` | First working "draw with your index finger" loop. |
